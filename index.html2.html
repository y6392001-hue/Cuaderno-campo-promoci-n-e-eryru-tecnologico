Cambio de alcance: de pantalla gigante a tablet

Al comienzo se pensó en un autoservicio con pantalla táctil de gran formato, como las de las cadenas de comida rápida. Al evaluar costos de hardware, mantenimiento e instalación, no entraba en el presupuesto. El catálogo se adaptó a una tablet en modo kiosco y conserva la misma función.

Prototipo del buscador

Prueba el buscador con disponibilidad sobre datos de prueba. El prototipo está escrito en Python (carpeta prototipo/). Esta demostración aplica las mismas reglas y el mismo catálogo, para poder verlo sin instalar nada.

Ñe'ẽryru Tecnológico

Datos de prueba: los libros y las cantidades no son el inventario real de la biblioteca. Un libro (Los tres cerditos) no tiene cantidades cargadas a propósito, para probar el manejo de datos faltantes. La ubicación en estante y repisa sigue en desarrollo.

Cómo ejecutar el prototipo en Python

cd prototipo
python3 buscador.py principito
python3 buscador.py --categoria Teatro
python3 buscador.py                  # modo interactivo
python3 -m unittest -v test_buscador # pruebas automáticas

Requiere Python 3 y no usa librerías externas. El catálogo de prueba está en catalogo_prueba.json.

Diseño de la interfaz

Boceto presentado en la defensa del anteproyecto. A la izquierda, la pantalla principal con las seis categorías y el menú lateral. A la derecha, el resultado de abrir "Cuentos".

Cómo se usa

El usuario se acerca a la tablet, busca por título o autor, o entra por categoría. El sistema muestra la cantidad de ejemplares disponibles.

Nueva entrada

Escribe la observación y copia el código que se genera para pegarlo en script.js y subirlo a GitHub. Así la entrada queda para todos. Mientras tanto, se ve en este navegador con borde punteado.

Código para subir a GitHub

  1. Copia el código con el botón.
  2. En GitHub abre script.js y pulsa el lápiz para editarlo.
  3. Busca la línea ]; que está justo antes de const TYPES y pega el código justo antes de esa línea.
  4. Pulsa "Commit changes". La entrada aparece para todos.
